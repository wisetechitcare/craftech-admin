# Project Instructions

Before implementing any task, read and follow the rules defined in `AGENTS.md`.

`AGENTS.md` is the source of truth for project-specific coding standards, architecture, structure, naming conventions, reusability, testing, and other development practices.

Do not create or introduce patterns that conflict with `AGENTS.md`.

When implementing a task:

1. Inspect the existing codebase first.
2. Follow the existing project patterns.
3. Reuse existing implementations whenever possible.
4. Follow all applicable rules in `AGENTS.md`.
5. If a requested change conflicts with `AGENTS.md`, follow the user's explicit instruction.
